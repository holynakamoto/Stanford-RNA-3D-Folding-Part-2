# Competition Rules Summary

## Key Requirements

### Submission Limits
- **Maximum 5 submissions per day**
- **Up to 2 final submissions** can be selected for judging
- Submissions must be made through Kaggle Notebooks

### Team Rules
- **Maximum team size: 5 members**
- Team mergers allowed (must complete before Team Merger Deadline)
- Combined team submissions must not exceed daily limit

### Code Requirements
- **Winners must provide open source code** (OSI-approved license, no commercial restrictions)
- Code must be capable of generating the winning submission
- Must include training code, inference code, and computational environment description
- Detailed methodology documentation required

### External Data & Tools
- External data must be **publicly available** and **reasonably accessible** to all participants
- Must meet "Reasonableness Standard" (not excessively expensive)
- Pre-trained models allowed if publicly available
- Automated ML tools (AMLT) allowed if properly licensed

### Data Usage
- Competition data licensed under **CC BY 4.0**
- Use only for competition participation and academic research
- No redistribution to non-participants
- Must notify Kaggle of any unauthorized access

### Code Sharing
- **No private code sharing** between teams (except within your team)
- **Public code sharing allowed** on Kaggle forums (must be OSI-licensed)
- Open source code used must be OSI-approved with no commercial restrictions

### Eligibility
- Must be 18+ (or age of majority in your jurisdiction)
- Not eligible if resident of: Crimea, DNR, LNR, Cuba, Iran, Syria, North Korea
- Employees of Competition Entities can participate but cannot win prizes
- Winners must not have privileged access to test data

### Winner Obligations
- Deliver final model code and documentation
- Grant open source license to Competition Sponsor
- Sign prize acceptance documents
- Provide detailed methodology description
- Link to code repository with reproduction instructions

## Important Dates
- **Entry Deadline**: March 18, 2026
- **Team Merger Deadline**: March 18, 2026
- **Competition End**: March 25, 2026

## Compliance Checklist

Before submitting:
- [ ] Code is open source compatible (OSI-approved license)
- [ ] External data/tools are publicly available and reasonably accessible
- [ ] No private code sharing outside your team
- [ ] Submission format matches requirements exactly
- [ ] Code can reproduce the submission
- [ ] All dependencies are documented
- [ ] Computational environment is described
